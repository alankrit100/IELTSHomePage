# IELTS Excellence - A Modern Landing Page

This repository contains the source code for the "IELTS Excellence" landing page, a fully responsive and highly animated single-page application built with React, TypeScript, and Tailwind CSS. The project showcases modern UI/UX principles and advanced frontend development techniques to create an engaging user experience for a fictional IELTS coaching service.

## ✨ Features

This project is packed with features designed to demonstrate proficiency in modern web development:

* **Fully Responsive Design**: The layout seamlessly adapts to all screen sizes, from mobile phones to widescreen desktops.
* **Dynamic UI Components**:
    * **Interactive Hero Section**: Features a dynamic, moving gradient background, parallax effects on decorative blobs, and smooth fade-in animations.
    * **Animated "How It Works" Carousel**: An interactive carousel powered by Embla and `lottie-react` to guide users through the process with unique animations for each step.
    * **Interactive "Features" Section**: An engaging tab-like system where selecting a feature updates the displayed image with a smooth animation.
    * **Smooth Testimonials Carousel**: A polished carousel for displaying user testimonials with themed, colored shadows and fluid transitions.
* **Dynamic Navigation Bar**: The navigation bar is initially transparent and transitions to a blurred, solid background on scroll for a modern, professional look.
* **Professional Forms**: The contact form is built with `react-hook-form` for efficient state management and validation.
* **Elegant Footer**: A compact and sophisticated footer that provides essential links and branding.

## 🛠️ Tech Stack

This project was built using a modern and powerful set of technologies:

* **Framework**: [React 18](https://reactjs.org/)
* **Language**: [TypeScript](https://www.typescriptlang.org/)
* **Build Tool**: [Vite](https://vitejs.dev/)
* **Styling**: [Tailwind CSS](https://tailwindcss.com/)
* **UI Components**: Built with [shadcn/ui](https://ui.shadcn.com/), which utilizes Radix UI and Tailwind CSS for accessible and composable components.
* **Animations**:
    * [Framer Motion](https://www.framer.com/motion/)
    * [Lottie React](https://lottiereact.com/)
    * `tailwindcss-animate`
* **Form Management**: [React Hook Form](https://react-hook-form.com/)
* **Linting**: [ESLint](https://eslint.org/)
